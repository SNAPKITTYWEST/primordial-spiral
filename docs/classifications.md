- **TRADITIONAL / SYMBOLIC**

## Invariants Policy

No quantity is declared invariant because a picture "looks the same."
Each candidate invariant must have:

1. Mathematical definition
2. Dylan implementation
3. MATLAB implementation
4. Numerical experiment
5. Reported result under stated tolerances
